# Community 与 Professional 能力

Unisence Community Edition 包含完整的平台基础能力，以及可免费安装的 Community 规则运行时。规则运行时作为独立进程运行，通过
Kafka、数据库配置和稳定的消息契约与平台组件协作。

## Community Edition

- 设备、产品、属性/事件物模型与系统管理；
- 数据接入、在线状态与 GreptimeDB 时序存储（当前值由时序库派生，不另建 Redis 影子）；
- 即时规则配置、启停、执行，以及向已登记 Kafka Topic 的规则输出；
- 透传路由：落库确认后按产品与消息类型转发到已登记 Topic；
- 窗口规则配置预览：可以创建、校验和保存，不能启用执行；
- `cn-driver-common` 与虚拟测试驱动。

即时规则由可安装的 `cn-rule-runtime-community` 组件执行。发行包包含规则运行时可运行工程（启动器与配置模板）；该组件以独立
JAR 加入该进程的
classpath，与管理端和数据引擎分别作为独立进程启动。部署方可覆盖配置，不由发行脚本锁定。

Community **尚未包含**：设备服务调用与下行、官方协议驱动、告警中心、按设备集过滤的 IoT 数据权限。物模型服务定义可以保存，但平台不会下发
invoke，也不会接收或落库服务回复。

## Professional

Professional 可选组件在 Community 能力之上提供窗口聚合执行、正式协议驱动和相应的商业支持。窗口运行时未安装时，窗口规则始终保持停用，
不会消费消息、维护窗口状态或产生窗口输出。官方 MQTT / Modbus / OPC UA 等协议驱动不在 Community 中；社区可基于
`cn-driver-common` 自研驱动，测试用虚拟驱动禁止用于生产接入。

具体可用能力以管理端能力查询和实际安装制品为准，不能通过修改业务配置伪造。

## 开源范围

开源版本提供规则配置、管理 API、脚本 SDK 和规则服务启动器。**规则执行实现不是开源源码。**

窗口规则的执行代码不开放。即时规则执行与窗口规则写在一起，因此两者的执行实现都不作为开源源码提供。

- **即时规则**：Community 以免费二进制提供完整执行能力；本仓库不提供该运行时源码。
- **窗口规则**：开源版本可配置预览，不能启用执行；执行属于 Professional 可选组件。

请勿把「Community 可免费使用即时规则」理解成「规则运行时源码全部开放」。
